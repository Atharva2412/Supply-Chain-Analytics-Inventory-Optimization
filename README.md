# 📦Supply Chain & Inventory Dashboard
### 1.  Supply Chain Analytics & Inventory Optimization
An end‑to‑end analytics workflow using **SQL Server, MySQL, and Power BI** to simulate inventory management, resolve data anomalies, and visualize supply chain KPIs for business decision‑making.


### 2. Purpose
This project demonstrates how businesses can use **data analytics and database management** to optimize supply chain operations. It focuses on **inventory accuracy, demand availability, supply shortages, and financial performance**, delivering executive‑ready dashboards for decision support.

### 3.	Tech Stack
The dashboard was built using the following tools and technologies:<br>
•	🗄️  **SQL Server / MySQL** – Data cleaning, validation, joins, anomaly resolution.<br>
•	📊 **Power BI** – Interactive dashboards and KPI visualization.<br>
•	📝 **DAX & Power Query** – Business calculations, dynamic data connections.<br>
•	📁 File Formats – `.sql` for queries, `.pbix` for dashboards, `.pdf/.pptx` for reports.

### 4.	Data Source
- Synthetic transactional inventory dataset across multiple stores.  
- Features include: Product IDs, Pricing Catalogs, Demand, Availability, Supply Shortage, Profit/Loss.  
- Data migrated and validated between **SQL Server and MySQL** for consistency.  


### 5.	Features 
•	Business Problem :
Companies often face **broken product records, mismatched identifiers, and inaccurate supply chain reporting**, leading to poor inventory decisions. 

• Key questions such as:
- 📊 How accurate are product identifiers across databases?  
- ⏱️ What is the average demand and availability across stores?  
- 📉 What percentage of supply shortages occur daily?  
- 💰 How do profits compare to deficit losses?  
- 🔄 How can data workflows be migrated between SQL Server and MySQL without breaking reporting?  
- 🏪 Which stores face the highest shortages and lowest availability? .

•	Goal of the Dashboard  
- Ensures **100% product identifier accuracy** across databases.  
- Tracks **average demand, availability, and supply shortages**.  
- Separates **store profits vs. deficit losses** using DAX measures.  
- Provides **executive‑facing KPIs** for supply chain health. 
  
•	Walkthrough of Key Visuals
- **KPIs (Top Left):** Avg Demand, Availability %, Supply Shortage %, Profit vs. Loss.  
- **Inventory Accuracy:** SQL queries resolved invalid product mappings.  
- **Dynamic Data Connections:** Power Query enabled switching between SQL Server and MySQL without breaking visuals.  
- **Financial Performance:** SUMX + FILTER DAX formulas separated profits from losses.  
- **Supply Chain Dashboard:** Clean visuals for demand, shortage, and availability trends. 


•	Business Impact & Insights
- ✅ **Improved Data Accuracy:** Eliminated anomalies and mismatched product IDs.  
- 📈 **Better Decision‑Making:** Clear KPIs for demand vs. supply shortages.  
- 💰 **Financial Clarity:** Automated profit/loss separation for executives.  
- 🔄 **Flexible Data Sources:** Dynamic connections across SQL platforms.  
- 🏪 **Operational Efficiency:** Store‑level insights for inventory optimization.
